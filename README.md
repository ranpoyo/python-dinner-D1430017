## 3. 問題回答

### 問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？
因為 `"4"` 加上雙引號後在 Python 中屬於**字串（`str`）**型別，代表的是文字而非數值。在 Python 裡，浮點數（`float`，如應付總額 `1220.0`）無法直接與字串進行除法運算（會發生 `TypeError` 錯誤），因此必須先透過 `int()` 將 `"4"` 轉換為整數（`int`），才能正確計算出每人分攤的費用。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
* **應付總額會變成**：**1,210 元**。
  * 算式：先扣折價券 $1200 - 100 = 1100$ 元，再計算 10% 服務費 $1100 \times 0.10 = 110$ 元，最後總額為 $1100 + 110 = 1210$ 元。
* **結果不同的原因**：因為計算服務費的「基準金額（母數）」不同。題目規定是以「原始餐費 1,200 元」為基準計算 10% 服務費（120 元）；若先扣除 100 元折價券，計算服務費的基準會縮小為 1,100 元，導致服務費少了 10 元（變成 110 元），進而使最終應付總額從 1,220 元減少為 1,210 元。
